# Mise – Wochenküche

Rezept- und Einkaufs-App für zwei, als Web-App (PWA) fürs iPhone.

**App öffnen:** https://devoslibrary.github.io/mise/
In Safari öffnen › Teilen › „Zum Home-Bildschirm“.

- 120 Rezepte (inkl. Meal Prep) mit Schritt-Illustrationen, Nährwerten und Preisschätzung
- Kochmodus mit Timern, eigene Rezepte, Bewertungen, Wochentage, Nährwerte der Woche
- Filter nach Laden, Lust, Küchengeräten, Vorrat und Abneigungen
- Einkaufsliste nach Gängen und Packungsgrößen, eigene Artikel, Reste in den Vorrat
- Wochenplan per Link teilen, 4-Wochen-Historie (pro Gerät)
- Offline-fähig, keine laufenden Kosten
