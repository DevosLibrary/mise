# Mise – Wochenküche

Rezept- und Einkaufs-App für zwei, als Web-App (PWA) fürs iPhone.

**App öffnen:** https://devoslibrary.github.io/mise/
In Safari öffnen › Teilen › „Zum Home-Bildschirm“.

- 103 Rezepte mit Schritt-Illustrationen, Nährwerten und Preisschätzung
- Filter nach Laden, Lust, Küchengeräten, Vorrat und Abneigungen
- Einkaufsliste nach Gängen sortiert, Wochenplan per Link teilen
- Offline-fähig, keine laufenden Kosten
